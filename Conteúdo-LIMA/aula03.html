Categorias de Conteúdo HTML5

Elementos de Blocos

Ocupam toda a largura disponível, exemplo: <div> <p>, <h1>, <section>, <em>, <img>

Elementos de Linha

Ocupam apenas o espaço necessario na linha, exemplo: <a> <span>, <strong>, <em>, <img>

Regras Importantes

Elementos de linha não devem conter elementos de bloco

Exemplo incorreto:
Texto
Exemplo correto:
Texto

Categorias de conteúdo:

Metada Content

São informações de configuração do arquivo HTML

<title> informa o titúlo da página.

<meta> definir codificação.

<link> e <style> importar/anexar CSS.

<script> importar/anexar comandos JavaScript.

Flow Content

: Representa a maior parte dos elementos usados no body.

<div> : criar uma divisão genérica, agrupar "pedaços" de código.

<p>: criar paragrafo dentro da página.

<section> : agrupa conteúdos que partilham do mesmo assunto/idéia.

<article> : conteúdo independente e completo por si só (faz sentido sozinho).

<img> : importar imagem, desenho, foto (não precisa de tag de fechamento).

<form> : criar formulários, o usuário pode digitar dados e/ou enviar mensagens, fazer login.

Sectioning Content

Organizar grandes áreas do documento

<section> : agrupa conteúdos que partilham do mesmo assunto/idéia.

<article> : conteúdo independente e completo por si só (faz sentido sozinho).

<aside> : serve para guarad o conteúdo secundário/lateral (links relacionados, anúncios, biografia e etc).

<nav> agrupar links de navegação.

Heading Content

h1, h2, h3, h4, h5 e h6 : Adicionar títulos e subtítulos

<hgroup> : agrupar elementos de título, exemplo:

Aprenda HTML
SENAI Americana

Phrasing Content

Elementos que marcam textos ou partes de texto

<span> : Um bloco genérioco, não muda nada sozinho, porém pode aplicar CSS ou chamar funções/comportamento com JavaScript.

<a> : criar um link para direcionar o usuário para outra página, utilizando o atributo href. Exemplo: Clink aqui para conhecer o bitcoin

<strong> : serve para deixar uma parte do texto em negrito

<em> : serve para deixar uma parte do texto em itálico

<mark> : serve para adicionar um marcador em uma parte do texto

<img> : importar imagem, desenho, foto (não precisa de tag de fechamento).

Embedded Content

Ultilizado para inserir um conteúdo externo.

<img> : importar imagem, desenho, foto (não precisa de tag de fechamento).

<video> : adicionar o vídeo(pode mostar botões de play e pause).

<canvas> : criar uma tela em branco que poderá ser usada pelo JavaScript.

<svg> : desenhar gráficos baseados em vetores.

<iframe> : colocar outra página inteira dentro do seu website (muito usado para adicionar mapas e vídeos).

Interactive Content

Permite interações com o usuário.

<a> : criar um link para direcionar o usuário para outra página, utilizando o atributo href.

<button> : cria botão. Exemplo

<input> : usado para receber dados do usuário. Dentre os dados aceitos estão:

type="text": campo de texto curto; type="password": oculta os caracteres digitados; type="email" ou "number": valida dados específicos; type="checkbox" ou "radio": caixas de marcação e escolha única. ***type é uma tag que não precisa de fechamento

<select> : criar um acaixa de seleção em formato de linha suspensa(dropdown)

<textarea> : criar uma caixa com várias linhas, serve para textos longos, comentários, mensagens e biografias

Listas em html

Lista não ordenada (ul). Exemplo:

  • Item 1
  • Item 2
  • Item 3

Lista ordenada (ol). Exemplo:

  1. Item 1
  2. Item 2
  3. Item 3
